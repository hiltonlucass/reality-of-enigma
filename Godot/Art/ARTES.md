# Assets da arena V2

cast.png e bosses.png são cópias das pranchas de conceitos V1 aprovadas pelo usuário. Battlefield.cs usa regiões dessas texturas como retratos; não são sprites isolados nem animações prontas.

kael-base.png é um novo asset com transparência, gerado pela ferramenta integrada de imagens e baseado na identidade aprovada. Usado como sprite de repouso provisório, com animação procedural. Ainda requer adaptação final de grade, paleta e quadros para produção.

## Prompt do Kael

Use case: stylized-concept. Game asset for Godot 2D combat prototype. Reference role: preserve the approved KAEL identity from the top-left character of this sheet. Create ONLY ONE isolated full-body playable pixel art sprite of Kael base, no other characters. Adult short lean athletic war veteran with dark black bowl haircut, slate gray and desaturated teal scout armor, teal scarf, brown belts, two short steel blades, same recognizable face and outfit design simplified for small game resolution. Three-quarter combat idle pose facing RIGHT, feet planted, blades ready, silhouette extremely readable. Deliberate chunky square pixels with a limited 24-color-style palette, approximately a 96x128 logical sprite enlarged using hard nearest-neighbor-style edges. No fine painterly rendering, no smooth vector gradients, no label, no text, no frame, no ground, no shadow outside sprite, no backdrop. Entire body and both blades fit with ample transparent margin. Genuine transparent background. This must look like a usable game sprite rather than a detailed character poster.
